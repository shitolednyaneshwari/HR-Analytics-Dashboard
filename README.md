# HR Analytics Dashboard | Power BI
## 📊 Project Overview
This project is an HR Analytics Dashboard created using Microsoft Power BI.
The dashboard provides useful insights into employee data, attrition, departments, job roles, education, age groups, marital status, and job satisfaction.
## 🎯 Objectives
- Analyze employee data
- Understand employee attrition
- Calculate attrition rate
- Analyze employees by department
- Analyze employees by age and gender
- Identify attrition by job role
- Analyze employee education
- Understand marital status distribution
- Analyze job satisfaction ratings
- Create an interactive HR dashboard
## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization
## 📈 Key Dashboard Metrics
- Total Employees: 282
- Attrition: 44
- Attrition Rate: 15.60%
- Active Employees: 238
- Average Age: 37
## 📊 Dashboard Features
- Attrition by Department
- Employee by Gender and Age Group
- Attrition by Job Role
- Employee by Education Field
- Employee and Attrition by Marital Status
- Job Satisfaction Rating
- Interactive filters for education and employee analysis
## 🔍 Key Insights
- The dashboard shows an overall attrition rate of 15.60%.
- It provides a comparison of attrition across departments.
- Employee distribution can be analyzed across different age groups and genders.
- Job roles can be compared based on attrition.
- Education fields can be analyzed to understand employee distribution.
- Job satisfaction ratings can be compared across different job roles.
